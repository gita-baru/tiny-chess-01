A 4 KB Python chess engine (v6): 0x88 board, negamax alpha-beta with transposition table, killer moves, null-move pruning, late-move reductions and quiescence search, to a fixed node budget. Material + piece-square tables with tapered king endgame, plus repetition avoidance that scores a twice-seen position as a draw. main.py is packed from the readable source with the kit's makefun compress; practice trials average ~1,365 Elo.

## Run it

```sh
MAKEFUN_ENV_URL=$MAKEFUN_ENV_URL python3 main.py
```
